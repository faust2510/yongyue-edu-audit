## 1. 解析口径（已全量核验，可复算）

- 四个 sheet：`家教`（sheet1）、`文26下`（sheet2）、`A`（sheet3）、`B12`（sheet4）。
- 表格是左右两个镜像日历网格，列对 = 月份（B/C=2026-07 … Q/R=2027-02）；每个列对中
  前列=该月日期(1~31 整数)，后列=该日期的事件文本（多行 \n 分隔，一行=一次课次）。
  A/J 列为星期标签（一~日），仅作视觉参考；真实日期/星期由「月份列 + 日期数字」推导并
  用该日实际 weekday 复核（511 行 weekday 全部自洽）。
- 事件文本解析（`parse_lesson_line`）：
  - 行首可选 `L<课次号>`；后接课程名（去班级后缀归一为 `subject_name`）+ 班级标注
    （`A123B34` 等，原样保留在 `batch_label`）+ 括号时刻（`（10-12点）`/`（19:15-21:15 ）`）。
  - 关键词识别 `考试` / `讲座` / `师生互动` → `lesson_kind`。
  - 节日/图例文本（实践周/元旦/平安夜/圣诞节/春节/除夕/周末/假期/重要节日/日期不确定/
    基础信仰/专文写作/福音与中国传统文化 等右下角 legend）全部排除，不进课表。
- 解析计数（raw，逐格）：家教 157、文26下 183、A 93、B12 78，合计 511（见 sessions_raw.csv）。
- **与既有 count_sessions.py 基准的差异说明**：旧脚本启发式只统计含「点」时刻或班标注的
  "中文点"行，漏掉家教 sheet 中 38 条使用英文冒号时刻（`7:45-9:45`/`19:15-21:15`）且无班标注
  的真实课次（旧基准家教 119 = 157 − 38）。经与文26下逐格比对，这 38 条均为真实课次
  （与文26下同刻同课，家教仅缺班标注）→ **本契约家教 = 157 条**。

## 2. 三源关系与实体合并（默认裁决，待用户确认 A/B 两点见 §7）

- **家教 sheet 与文26下 是同一套 B 部课表的"网课学员镜像"**：家教 157 条在

  家教 sheet 无班标注、无 课堂管理/使徒行传 两门（分别因 B3 全勤/线下出勤？差异仅此二课
  缺席）——见 §7 待决 A（家教班级归属）与 B（网课受众如何落库）。
- **A 部 93 条**：其中 50 条与文26下同刻同课（跨部合班课：逻辑一/使徒行传/护教学基础/
  基督教与法律导论 等的 A+B 组合视角，两表一致），43 条为 A 部专属课（基础信仰 A1 4、
  神论 A123 6、圣灵论 A123 5、摩西五经 A123 5、讲道法 A23 6、师生互动 14、改革宗讲座 2、
  救恩论 A123 密集 1 = 43）。
- **合并规则（normalize_sessions.py v3）**：仅当 (date, subject, lesson_no, **start_time**,
  end_time) 全部一致才把跨源行并入一个实体（同刻同科同课次 = 同一节课的不同 sheet 视角），
  否则各自独立。→ 主表实体 226 条：
  - 显式时刻 201 条；
  - A 部无时刻专属课 25 条赋默认时刻并标 `time_source=default`（详见 §6）。
- 主表每条含 `source_sheet`/`cell_ref` 全来源（分号），`raw_text` 保留全部原样（`;;` 分隔）
  → 每条 op.session 均可回溯到 xlsx 单元格。full_sources.csv 433 行逐源全部配对实体，
  无遗漏、无重复（校验通过）。

## 9. 给工程师的实现要点（t2）

1. 读 sessions.csv 逐行 → op.session.create：date+start/end（Asia/Shanghai→UTC 转换）、
   subject_id=科目（按 subject_name 查/建）、batch_id=组合 batch（按 batch_label 查/建）、
   course_id=batch 归属 course、faculty_id=占位「待定」教师、kind/考试等放 name 或备注；
2. 幂等：以 (date, subject, batch, start) 唯一性判重（先查后建），脚本可重跑；
3. 冲突预检：同一 batch 同刻不同科目 = 真实冲突（如 神论 A123 与 wen 同日无冲突因为批次不同）；
   跨部同课 A123B34 vs CB34 若同时建会产生 B34 同刻冲突 → 按 §7 C 默认只建 A123B34 主行；
4. A 部 default 时刻行已写死时间，直接使用；kind=考试 建为普通 session 但 name/备注带「考试」。
5. 所有科目/批次/教师/教室建档遵循 §4，code 唯一。
