## 1. 研究对象与结论摘要（规范来源，非代码来源）

钉钉（家校/班级群）与企业微信教育版（家校互联）的「家校工作台」是面向**家长/老师双角色、高频率、低龄化与老龄化并存的用户群**的移动优先工作台。其公认的布局与交互事实如下（来源见 §9）：

| 维度 | 钉钉 / 企微做法（规范事实） | 本项目用法 |
|---|---|---|
| 移动端骨架 | 底部固定 Tab 栏（消息 / 通讯录 / 工作台 / 我的，≤5 个），Tab 带未读角标 | 移动端底部 5 Tab（见 §3.3） |
| 工作台页面 | 顶部搜索 + 「常用应用」金刚区宫格（大图标、可置顶排序）+ 「全部应用」分组宫格（按职能分组、分组标题）+ 应用可收藏/分组 | 首页工作台宫格 + 分组标题（见 §4） |
| 教育版特有能力 | 家校通讯录（按「老师 / 家长 / 学生」组织）、班级群、通知公告、打卡、审批 | 对应 B8 通讯录、B9 私信、B5 通知、B6 打卡 |
| PC / 网页端 | 顶栏（品牌、搜索、通知、头像）+ 左侧导航（分组标题 + 图标菜单 + 激活态右竖条）+ 右侧内容区；工作台应用同样分组宫格 | 桌面/平板顶栏 + 左侧角色导航（见 §3.2） |
| 色彩 | 蓝 / 蓝绿主色系（钉钉蓝、企微蓝，功能色 + 中性色分层） | 蓝绿双主色体系（见 §5.1） |
| 文字 | 大字号优先：正文 ≥ 15–16px，标题更醒目；中老年/家长场景遵循适老化规范（正文 ≥ 16px、点击区 ≥ 44×44） | 16px 正文基线（见 §5.3） |
| 形状 | 圆角卡片（卡片 12–20px 圆角）、圆角按钮、胶囊标签 | 圆角刻度体系（见 §5.4） |
| 状态 | 明确的成功 / 警告 / 错误 / 进行中状态色 + 浅色底 chip | 状态色体系（见 §5.2） |

**研究结论**：家校工作台 = 「移动优先的双层导航（底部 Tab / 左侧分组导航）+ 宫格化应用入口（分组标题 + 图标卡 + 角标）+ 蓝绿清爽色系 + 大字号圆角卡片」。本项目是 Odoo 响应的门户（桌面+移动），因此落地为：**桌面端顶栏+左侧角色导航、移动端底部 Tab、首页宫格分组化**三件套，其余页面套用统一令牌。

## 4. 首页工作台宫格规范

沿用现有 `edu_dashboard` 模板与 `o_portal_docs` / `o_portal_index_card` DOM，新增**分组标题行**；不重排卡片、不改 URL 与图标语义（A6 图标语义化已在 v2 完成，保留）。

### 4.1 分组

- 分组标题行 = 左侧 9×9 圆角方块（主色，`oe-cat-dot` 既有样式族）+ 标题（`--text-xl` 20px / 600）+ 右侧「查看全部」链接（若有）。
- 建议分组（按现有卡片归类，数量随 B8/B9/B10 增补）：
  - **学习中心**：课表、作业、考试、课程、成绩册、在线测验、学科与注册；

## 5. 设计令牌体系（可直接落地的 CSS 变量）

建议在 `custom_addons/edu_portal/static/src/css/` 新增 `theme-b11.css`（或并入 portal.css 顶部 `:root`），**变量全部挂 `--` 前缀**，与现有 `var(--gutter-x)` 等 Bootstrap 变量共存；`!important` 只允许在覆盖 Odoo 默认样式时按现有习惯使用。

## 6. 交互与状态规范

### 6.1 反馈态
- **hover**：浅填充（导航/列表 `--fill-hover`）；卡片上浮 -2px + `--shadow-md`；按钮加深（主色 hover 用 `--brand-600`）。
- **active/pressed**：`--fill-active` 或无位移无阴影，150ms。
- **focus**：`outline:0` + `box-shadow:0 0 0 3px rgba(14,123,242,.18)`（主色 18% 环），键盘可达必须保留。
- **disabled**：`--text-disabled` + 无背景；**不凭空禁用既有入口**（零功能丢失）。

### 6.2 动效
- 时长 150–250ms、`cubic-bezier(.2,.6,.3,1)`；仅变换 opacity/transform/box-shadow/background；尊重 `prefers-reduced-motion`。

### 6.3 角标 / 未读
- 计数角标：≥100 显示 `99+`；0 值灰底（沿用 `oe_count_zero`）；红点（8px）仅用于「仅提醒不计数」。
- 未读数据源不变：B5 通知引擎（布告栏已读表）+ B9 私信 30s 轮询，**角标只读引擎、不在视觉层自造计数**。
- 顶栏通知铃与底部「消息」Tab、左侧「消息」菜单共用同一未读数。

### 6.4 空态 / 加载 / 错误
- 空态沿用全站优秀范本格式（说明 + 下一步动作，见 `docs/ux-audit.md` §3.3 标杆页），只换新令牌色。
- 加载：宫格区可用骨架卡（灰底 16px 圆角占位，宽度 100%），其余沿用 Odoo 默认 spinner。
- 错误/未授权提示：`--danger-soft` 卡片 + 返回按钮（A7 面包屑兜底）。

## 7. 零功能丢失对照清单（P4 每页改造必做）

1. **路由全量核对**：以 `scripts/check_english.py` 的 `ROUTES` 清单为基线（学生 `stu@local`、教师 `faculty@local` 两角色），**逐条改造前/后各跑一遍**，随后增补 B8/B9/B10/A9 新路由（`/my/contacts`、`/my/messages`、`/my/calendar`、`/alumni/jobs` 等，以实际实现为准）与公开站 `/apply` 等。

5. **无障碍抽查**：正文 ≥15px、点击区 ≥44px、focus 可见、`prefers-reduced-motion`。
6. **验收截图**：每页「改前/改后」成对截图（桌面 + 375px 宽移动），随任务输出附件记录，供 t10 评审对照。
