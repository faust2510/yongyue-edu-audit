## 一、工作台 · 应用板块（应用网格 / 导航 / 状态表达）

### 1.1 钉钉工作台（移动端 + PC 端）

**移动端工作台结构**（钉钉帮助中心「如何自定义工作台」等公开资料归纳）：

```
┌─────────────────────────────────────┐
│ 顶栏：搜索框 ── 工作台标题 ──「编辑」   │
├─────────────────────────────────────┤
│ 「常用应用」金刚区：4~5 列大图标宫格    │
│   （可置顶：长按/编辑态拖动排序）       │
│ 「全部应用」分组宫格：                 │
│   分组标题（职能名，如 教务/家校/行政）  │
│   ┌──┬──┬──┐  每个应用 = 图标+名称    │
│   └──┴──┴──┘  图标右上可带数字角标     │
│ （分组与分组之间的排序可整体上下移）     │
└─────────────────────────────────────┘
```

- **金刚区（常用应用）**：把高频应用固定在首屏宫格，**可置顶、可拖动排序**；第二屏开始是「全部应用」按职能分组。帮用户把「高频直达」与「全量可查」分层。
- **自定义能力**：管理员/用户可进入「编辑工作台」——重新排序、增删分组、选择宫格尺寸（大/小图标）、换主题（官方帮助中心有「宫格尺寸」「工作台主题」专项条目）。宫格 = 图标 + 名称 + 角标（未读/待办计数），0 值灰底。
- **PC 端工作台**：桌面客户端同样提供工作台页（开放平台「PC 端官方组件」文档），应用以宫格+分组呈现；主界面的左侧导航（消息/通讯录/工作台/我的）与移动端底部 Tab 一一对应——**同一信息架构，两套承载**。

**→ 可借鉴到本系统**：
- **应用面板（`/my/home` 首页宫格）**：B11 已规划分组标题；进一步可增「常用应用」置顶区（高频四件套：课表/打卡/校历/消息），「全部应用」按学习中心/校园生活/沟通/个人事务分组；支持编辑态拖拽排序（明文存 localStorage 或用户表）；角标（布告栏/消息未读）0 值灰底已沿用 `oe_count_zero`。
- **宫格尺寸两档**：小屏 2 列/大屏 4 列（B11 已定），可再给「紧凑/大图标」切换，适配教师中老年家长群体（适老化）。

### 1.2 企业微信工作台（应用排序与常用栏）

企业微信帮助中心「如何设置应用排序」原文要点：

- **应用分组**：管理员可在「工作台管理 → 修改应用分组排序」中，用**分组右侧“⋯”菜单上移/下移整组**；进入分组编辑后，**点击应用左侧“三横”图标上下拖动**调整应用顺序（拖拽排序是标准交互）。
- **常用应用栏**：手机端**长按应用**即可「添加至常用/从常用移除」；也可在「编辑工作台」页面操作；第三方应用右上角“⋯”也有「添加至常用」。
- **空组隐藏原则**：**没有任何常用应用时，工作台不显示“常用”区域**——空则隐，不占视觉位。
- **PC 端**：鼠标悬停应用卡片，右上角出现“⋯”菜单（hover 才露操作，避免界面常驻杂物）。

**→ 可借鉴到本系统**：
- 应用面板采用「悬停/编辑态才显示操作」的渐进披露（桌面 hover、移动进入编辑态或长按），避免卡片区满是“⋯”。
- 分组/常用区**空则隐藏**：分组标题下无卡片时不渲染该组（B11 §4.1 分组标题行需加此守卫）。
- 拖拽排序优先做「编辑态」版本（点「编辑」进入网格可拖动），比常驻拖拽更易实现且不易误触。

### 1.3 飞书工作台

- 飞书工作台提供「我的常用」小组件：可把高频应用置顶成小组件卡片（官方帮助中心「“我的常用”小组件使用手册」），与钉钉金刚区同思路。
- 管理员可设置工作台应用展示方式（官方帮助中心「Admin | Set how apps are displayed in Workplace」）：工作台应用可分组/排序/控制可见性，企业可定制工作台首页（「定制工作台解决方案」行业页）。
- 飞书桌面端主界面为左侧应用导航栏 + 顶部搜索 + 右侧内容区；工作台应用同样支持分组宫格。

**→ 可借鉴到本系统**：桌面端「左侧角色导航 + 分组标题」（B11 §3.2 已规划）与飞书/钉钉 PC 一致；「我的常用」小组件思路可直接落到 `/my/home` 顶部常驻条（课表+今日节次+打卡进度一屏聚合）。

### 1.4 桌面 vs 移动差异（工作台维度）

| 维度 | 桌面端 | 移动端 |
|---|---|---|
| 骨架 | 左侧导航 + 顶栏（搜索/通知/头像），内容区宫格 | 底部 Tab（≤5）+ 工作台页宫格 |
| 应用排序 | hover 应用右上“⋯”操作 | 长按应用 / 编辑工作台页 |
| 常用区维护 | 打开应用后顶栏右键 tab | 长按即加/移除，路径最短 |
| 搜索 | 顶栏常驻搜索框（宽 320–480） | 搜索图标点击展开 |

## 二、排课 / 课表（周视图矩阵、批量、冲突、周次）

### 2.1 国内排课系统的行业通用交互（多来源交叉验证）

公开的政府采购需求文件与排课软件介绍反复出现同一条「图形化排课」标准，堪称国内排课交互的事实基线（内蒙古/福建采购文件原文归纳）：

> 「要求按照图形化课表方格的方式显示排课课表信息，系统**实时检测各类课表冲突**，冲突使用**不同颜色或符号标记**（可区分教室冲突、班级冲突、教师冲突），**空闲可排课处显示为空白/绿色**」。

- 即：**时间×星期（或×教室/班级）的方格矩阵**；冲突**分色标记而非弹窗轰炸**；空闲格留白即可排。
- 「智慧排课系统」（华军软件园收录）功能描述补充：可视化操作=**拖拽课程块实现添加/删除/修改**，便于及时发现并解决冲突；冲突检测覆盖教师/学生/课程/场地，**冲突时立即提示并智能推荐替代方案（调时段/换教室）**；支持**周视图/月视图/学期视图**多维度查看与 **PDF/Excel 导出**；教师可通过**移动端申请调代课**。
- 「水晶排课」「悦排课」等同类软件均提供**自动排课（规则引擎/遗传算法）与手工拖拽微调并存**的模式。

**→ 可借鉴到本系统（排课中心 = 后台「排课管理」周历）**：
- 现有后台周历（15 色块、撞时段 ValidationError 拦截）升级为**方格矩阵 + 分色冲突标记**：教师冲突红、教室冲突橙、班级冲突黄（或红字+浅底 chip，B11 状态色体系），被拦课时**在弹层里给出替代建议**（同教室其他空时段/同时段其他空教室），而非只报错。
- 保留**空闲格空白**语义：空时段整格可点 → 直接在该格新建课时（点格即建，见 3.1 日程模式）。
- 增加**批量操作**：按日整列批量指派（企微排班「按日期批量」同款）、整周复制（学期模板展开的第一阶）、Excel 下载/导入排课表。
- 「周/月/学期」视图切换：当前只有周历 → 加「学期总览」只读压缩视图（月历粒度），配合导出。

### 2.2 超级课程表（学生端课表 App，极客公园/太平洋电脑网报道）

- **桌面卡片**：课程名+时间+教室直接“钉”在桌面，瞄一眼即知早八课（对家长的「孩子的课表」= 每次打开 App 看，桌面卡片思路 = 门户首页卡片直接预览今日节次）。
- **周/日视图自由切换**、**多学期切换**：学生按“今天上什么”和“这周怎么排”两种心智切换视图。
- **扫码导课 / 分享课表**：导入路径多（教务系统导入/手动添课/扫码）。
- **计划页聚合**：今日课表 + 今日待办 + 成绩 + 社团信息一页聚合（“一眼掌握全局”）。

**→ 可借鉴到本系统**：
- **周课表门户 `/student/timetable`**（教师「我的教学安排」/家长「孩子的课表」）：加**日视图**与**「今天」定位**按钮；首页工作台加「今日课表」预览卡（类似桌面卡片，聚合今日 1~N 节 + 教室），减少进详情页次数。
- 视图中标注**周次/单双周**（与校历 B10 联动，节假停课自动灰显），解决“这周上不上课”的核内心智负担。

### 2.3 钉钉教育场景中的课表

- 钉钉帮助中心多条目显示**班级群挂课表**能力（“家校群有课程表吗”等帮助条目）；钉钉香港站有「补习导师排课系统」方案页（机构课表/约课场景）。钉钉本体不做排课，但**把课表作为班级群的挂件应用**（群内直达、通知触达）值得借鉴。

**→ 可借鉴到本系统**：把「调课/停课通知」挂到消息中心与布告栏（B5 通知引擎），调课成功后自动通知相关学生/教师——即 timetable-design.md 遗留项「批量调课通知学生」的交互依据。

## 三、日程 / 校历（视图切换、快速新建、重复周期）

### 3.1 钉钉日历（官方帮助中心「日历首页」「设置日历视图」「新建日程」「重复日程」）

**日历首页结构**（帮助中心配图归纳）：

```
┌─────────────────────────────────────┐
│ [搜索日程…]  [＋新事件]  [我的日历✔] [设置] │
├─────────────────────────────────────┤
│ 视图切换：列表 │ 日 │ 周 │ 月   （一键切换） │
│ ┌──────┬──────┬──────┐              │
│ │ 时间 │ 时间 │ 时间 │  周视图=时间线网格   │
│ │ 轴   │ 轴   │ 轴   │  事件按起止时间落格   │
│ └──────┴──────┴──────┘              │
```

- **一键视图切换**：列表/日/周/月，桌面端 4 视图；**移动端额外提供「三日视图」**（小屏上比周视图更可读的折中）；可自定义**每周起始日**；可开**第二时区**（跨时区协作）。
- **两种快速新建**：①点左上/右下“＋”按钮打开新建弹窗；②**直接点击或拖拽日历日期/时段**快速建日程（拖拽范围即起止时间）。
- **新建弹窗字段**：标题（会议/活动类型）、时间（含**重复周期**与时区）、参与人（必需/可选）、地点（高德导航/会议室）、视频会议、描述/议程/附件、提醒。
- **重复日程**：新建时点「不重复」→ 选 **每日/每周/每月/自定义周期**，“一次设置未来多周的重复日程”——**周期模板自动展开**（与 OpenEduCat「周模板→展开实例」同构）。
- 我的日历开关、搜索已有事件、日程颜色（「换新颜」= 日历配色）。

**→ 可借鉴到本系统（校历 B10 `/my/calendar`、`/my/academic-calendar`）**：
- 校历从纯列表升级为**列表 + 月视图双视图**，一键切换；学期事件（开学/考试周/假期）落格。
- **点格即建 / 拖拽建事件**：校历管理端（后台）与日程一致的快速新建；新建弹窗含**重复周期**（每周重复的固定活动，如每周三祷告会）——与「周期排课」共用同一套“重复规则”心智。
- 移动端校历提供**三日视图**替代缩成一团的周视图。
- **法定节假日/无课日整列灰显**（对应钉钉考勤“特殊日期”置灰思路，见 §4.1），并联动周课表的周次计算。

### 3.2 飞书日历 / 多维表格日历视图

- 飞书日历同为日/周/月/列表视图体系；飞书多维表格（Base）将任意数据表渲染为**日历视图**（帮助中心「使用多维表格的日历视图」）：把“数据表”当“日程源”，按日期字段渲染日历——适合校历这类“事件即数据行”的场景。
- 钉钉多维表格同样提供日历视图（help.dingtalk.io 帮助中心「日历视图」条目）。

**→ 可借鉴到本系统**：校历事件做成可筛选的数据视图（按事件类型/参与班级过滤日历），而不是固定死的一张表——工程量小、复用现有列表数据。

## 四、考勤 / 打卡（大按钮、状态色、异常就近处理、统计口径）

### 4.1 钉钉考勤（官方帮助中心「员工快速上手」「团队考勤」「排班管理」等）

**员工打卡页结构**（帮助中心配图归纳）：

```
┌────────────────────────────┐
│ 考勤应用（工作台进入）         │
│ ┌──────────────────────┐   │
│ │      「打卡」大按钮      │   │  ← 主行动一键
│ │      （状态色：正常绿/    │   │     迟到红/外出蓝）
│ │       加班、外出可切）    │   │
│ └──────────────────────┘   │
│ [查看规则]  [统计]  [申请] [设置] │  ← 顶部一排
└────────────────────────────┘
```

- **打卡路径**：工作台 → 考勤 → 打卡按钮；也可开启**快捷打卡**（一键直达打卡动作，免翻页）。
- **统计**：我的统计/团队统计两视角；**日/周/月口径切换**（公开评测常见截图：统计页顶部日/周/月筛选按钮）；异常项（迟到/早退/缺卡）用状态色标注，**点异常日期 → 详情 → “处理异常”**——处理入口挂在异常本身旁边（**就近操作**）。
- **团队考勤移动端**：管理员/组长在手机上可看**当日“已打卡 / 应打卡”人数**，对标红未打卡人员**一键提醒打卡**——移动端可做轻量管理，不必回电脑。
- **提醒**：缺卡次日提醒、异常未处理提醒（连续 14 天未处理则停推）。

**排班管理（对排课最直接的参照）**：行=员工、列=日期的矩阵，四种排法并存——①**按日**：点格子选班次/休息；②**按周期**：点格子选周期（如 14 天循环），从该日起自动铺满到月末（= 周期排课）；③**批量**：点某日**整列**批量赋班次给全员；④**Excel 排班**：下载模板→填→导入。另有**单双周循环**（“双周周期”开关：6 天工作周/5 天工作周交替）——与学校单双周课表完全同构。

**→ 可借鉴到本系统（`/my/checkins` 每日打卡、`/my/checkins/stats`）**：
- 打卡页保留**大按钮 + 状态色图例**（B11 状态色体系已有）；统计页补**日/周/月切换**（现为打卡日历+进度，可加统计口径切换）。
- **异常就近处理**：缺卡/迟到记录旁直接放「补卡申请」入口（衔接调课/请假审批流），而不是让用户去别的页面找申请表单。
- **团队视角移动化**：教师端「打卡统计」卡片（ux-audit P3 已建议教师首页补卡）升级为可下钻的应打卡/已打卡数 + 一键提醒。
- **排班四法 → 排课中心**：点格选课时、周期模板铺开、按日批量、Excel 导入——直接搬入 §2.1 的排课中心升级清单。

### 4.2 企业微信打卡（补卡多入口 = 就近操作范本）

官方帮助中心「打卡补卡相关问题」：**补卡申请有 5 个入口**——统计-我的统计点异常记录、申请页、审批页、本月待处理异常、打卡首页“提交补卡申请”按钮。**入口随规则显隐**：不满足补卡规则（无“允许补卡”、白名单、超时限）则入口**自动不出现**，避免无效操作。

**→ 可借鉴到本系统**：审批/申请的入口“规则驱动显隐”原则——无权限/不满足条件时**隐藏入口而非置灰报错**；异常处理入口在异常出现处就近给出（打卡页、统计页、消息提醒三个触点）。

## 五、审批 / 流程（代办聚合、快捷动作、状态流转）

### 5.1 钉钉 OA 审批（官方帮助中心「快速上手」「办理人手册」）

- **入口聚合**：待办可从**审批中心、工作通知、待办（To-Do）**三处收到并处理——消息触达处即处理处（就地操作）；发起方入口更多：审批首页/工作台/群聊插件均可一键发起。
- **角色**：审批人（同意/拒绝/转交/退回/加签/评论）、办理人（提交/转交/退回/加签/评论）、抄送人（仅评论）——**一个表单多种角色权限，操作集各自裁剪**。
- **动作集**：同意、拒绝、转交、退回、加签（会签/或签）、评论、下载详情；**委托设置**（出差时委托他人审批）。
- **状态可视化**：流程进度（当前节点/已过节点）随表单展示；审批结果同步回业务（请假→考勤统计、报销→资金流）。
- **模板化**：预置请假/报销/用章等模板，一键复制启用——业务方不必从零搭流程。

**→ 可借鉴到本系统（`/course/change/request` 调课申请、`/my/time_off` 请假、`/my/grievances` 投诉）**：
- **待办聚合**：消息中心/布告栏角标 + 首页提醒条把「待我审批」聚合展示（现首页已有 3 提醒条，可加类型筛选），点通知直达处理页。
- **快捷动作**：详情页顶部主行动“同意/驳回”常驻（避免滚到底）；教师端调课申请审批人（教务）可**转交/退回**并附评论。
- **状态流转进度条**：调课申请从「待审批→已通过→已生效（课表已更新）」的节点可视化，通过后自动触发课表刷新与通知（§2.3）。
- 审批与业务数据联动（钉钉“请假→考勤”同款）：调课通过 → 周课表与冲突检测数据即时更新。

## 六、桌面 vs 移动差异总表（五类功能）

| 功能类 | 桌面端做法 | 移动端做法 | 本系统落地 |
|---|---|---|---|
| 工作台 | 左侧导航+顶栏搜索，hover 露操作 | 底部 Tab≤5，长按/编辑态维护常用、宫格直达 | B11 骨架已按此定稿 |
| 排课 | 方格矩阵+拖拽+批量+Excel；管理为主 | 查看课表为主+移动端提交调代课申请 | 后台排课中心（桌面）、门户课表（移动） |
| 日程 | 4 视图+拖拽建事件+第二时区 | 5 视图含三日视图、右下角“＋”（拇指区） | 校历移动端加三日视图 |
| 考勤 | 排班/规则/报表管理 | 打卡大按钮、统计、异常处理、团队轻量管理 | 打卡大按钮保留；统计加减口径；提醒 |
| 审批 | 处理+下载+管理 | 通知/待办直达处理，动作集裁剪 | 消息角标+详情页快捷动作 |

**通用设计原则提炼**（五类功能反复出现的共同模式）：
1. **就近操作**：处理入口挂在异常/待办发生处（补卡 5 入口、点异常即处理、通知即处理）；
2. **状态可见**：冲突/异常/未读用分色与角标表达，允许颜色+文本双重通道（适老化）；
3. **空则隐藏**：无常用应用不显示常用区、无权不显示入口、空闲格留白；
4. **视图切换**：列表/日/周/月/三日视图一键切换，适配“今天/本周/全学期”三种心智；
5. **周期与批量**：重复日程一次建多周、周期排班、整列批量、Excel 导入——把重复劳动交给系统；
6. **规则驱动显隐**：入口显隐由权限/规则计算，而不是给无效按钮。
