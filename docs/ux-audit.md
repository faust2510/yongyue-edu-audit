## 三、系统性发现（跨页面）

### 3.1 列表工具栏三件套（几乎每页出现）
- 现状：`排序依据 / 筛选依据 / 分组依据` 下拉；分组默认项写作 **「没有任何」**（No group by 直译）；筛选下拉出现「全部 全部」叠字观感。
- 影响：全站几十处重复出现的最扎眼机翻。
- 建议：一处模板/小组件统一改造——「没有任何」→「不分组」，「全部」按钮文案去重；工作量 S，收益全站。**P1**

### 3.3 空态质量分级
- **优秀（有解释+下一步，全站范本）**：`/library/media`、`/requested/queue/list`、`/meeting/information`、`/online/meeting`、`/checkins/stats` 口径说明、`/my-library` 底部说明。
