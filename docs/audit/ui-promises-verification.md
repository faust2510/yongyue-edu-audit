## 四、上传提示两条 —— 服务端真的照做（第 91 轮，未发现缺陷）

报销页写「仅支持 jpg / png / pdf，单个 ≤10MB」。实测：

```
.txt（13 字节）  → ?box=bad_type → 「收据仅支持 jpg / png / pdf 格式。」      ✅
11MB .png        → ?box=too_big  → 「单个收据文件不能超过 10MB。」            ✅
（另有 bad_image → 「图片文件已损坏或格式不受支持，请重新选择。」）           ✅
```

并做了**主动扫全仓**（因为我在 fix-then-sweep 上已栽过三次）：其余上传控件
（作业提交 / 资料上传 / 请假证明 / 头像 / 成绩导入）**都没有做尺寸或格式的承诺**，
唯一另一处有承诺的 `downloads_portal.xml` 用的是**动态值**（`max_mb` / `exts_text` 由控制器传）⇒ 不会漂。
**沉默不是撒谎** —— 没有承诺的地方不算缺陷。

## 六、方法（三轮里反复用到）

1. **把页面上写的话当成待验的断言**，逐条对实况 —— 不是读代码，是**照着做一遍**；
2. **判据落在渲染后的页面**，不是表头、命名或模板变量（我在这一条上犯过 5 次假阳性）；
3. **修完立刻全仓扫同款说法**（fix-then-sweep）—— 第 88 轮漏过一次，第 89 轮补上；
4. **新立的检查必须先证能红**，否则「全绿」可能只是「什么都没测」。
