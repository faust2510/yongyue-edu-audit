## 0. 先订正我上一轮的一句话（证据纪律）

上一轮我写「填了保存 → **页面没有任何提示**」。**这句不准确**，实测页面是有提示的：

```
本次没有新的改动（空白格 = 不录入，已录入且未修改的格子不会重复写入）。
```

也就是说，缺陷不是「没说」，而是**说错了**：用户明明填了越权格子，系统回他「没有新的改动」。
这比沉默更坏 —— 沉默让人怀疑，**错误归因让人以为「我填的和库里一样」**，从而放弃追问。
（订正的原因：我先跑了 GET ?saved=0 看渲染结果，才发现模板第 23-25 行本来就有这条 alert。）

## 1. 改动一：列按任教收敛（只对教师生效）

grade_entry.py 的 _columns() 新增 allowed_subject_ids 形参：

```
allowed_ids = None if pairs is None else {s for _b, s in pairs}
columns = _columns(..., allowed_subject_ids=allowed_ids)
# _columns 内：subjects = subjects.filtered(lambda s: s.id in allowed_subject_ids)
```

- 教务 / 超管 pairs is None ⇒ 传 None ⇒ **列一个不少**（他本来就能存全部列，收窄 = 平白降低能力）；
- 任课教师 ⇒ 传本人任教的科目 id 集合 ⇒ 只出他**存得进去**的列。
- 收敛口径与保存路由的 (batch.id, sub_id) in pairs **同一个 pairs**，不新增第二份判据。

### 1.1 效果（渲染后的页面读数）

| 身份 | 改前科目列 | 改后科目列 | 输入框 |
|---|---|---|---|
| 教师 faculty@local | **14** | **4**（古汉语课程 / 圣经概论（新旧约概论）/ 小要理问答 / 选修课程） | 16 = 4 列 × 4 人 |
| 教务 backoffice@local | 14 | **14（未变，正对照）** | 56 |

### 1.2 ★边界选择（Lead 要求列出供用户确认，我没有自己拍）

**问题**：某学生报了教师不任教的科目，那一列怎么办？

**我选的做法：对教师不出这一列**（教务照旧可见；学生的报课记录与既有分数**分毫未动**）。

理由三条：
1. **一致性**：该列对教师本来就是「写不进去」的（保存路由丢弃），把它渲染成可编辑输入框
   正是本次要修的缺陷；出列就必须是只读，而只读格是**共享网格里不存在的第二种渲染模式**
   （要动 assess_grid 的 JS/CSS），代价与本卡「只做收敛」的范围不成比例。
2. **最小可见面**：教师没有读取别的老师所授科目分数的正当需求（分数属个人数据，
   多给可见面是一条**隐私决策**，不该由一个 UI 修复顺手做掉）。
3. **无损**：教务侧那 14 列一分未少（§3 已取证），机构层面没有信息丢失。

**供用户确认的选项**（我按 (a) 实施，未选 (b)/(c)）：
  (a) 教师看不见该列（当前做法）
  (b) 教师看得见但**只读**（需要给共享网格加只读单元格模式）
  (c) 教师看得见但带锁图标 + 悬浮说明（同上，且要写文案）

## 2. 改动二：saved=0 必须给出**正确**的反馈

保存路由原本对被丢弃的格子静默 continue。现在计数并回传：

```
?saved=0&skip_scope=1        # 1 格因「不是您任教的科目」被忽略
?saved=0&skip_roster=2       # 2 格因「学生不在本班名单」被忽略
?saved=N&n=M&skip_scope=1    # 部分保存时也要说清另外有几格被忽略
```

模板新增一条 alert-warning，并让原来的「本次没有新的改动」**只在真的没有忽略时**出现。

### 2.1 页面文本（改后实测）

教师构造越权 POST（页面上已无该列，模拟旧页面/手工提交）：

```
POST m_5_36=88  ->  303 /grade-entry?batch_id=8&term_id=1&saved=0&skip_scope=1

[页面提示] 有 1 格未保存，已按权限忽略：1 格不是您任教的科目。
           可录范围：教务为全校；任课教师只限本人任教的班级与科目。
库内 subject 36: 61 -> 61   （仍然被丢弃，权限没有放松）
```

### 2.2 控制组（不能误报）

```
教师 POST 不带任何 m_* 格子  ->  ?saved=0（无 skip_scope）
[页面提示] 本次没有新的改动（空白格 = 不录入，已录入且未修改的格子不会重复写入）。
```

⇒ 该说的话说清、不该说的话不出现。

## 3. 三方复测（Lead 要求：教务列数不能变少）

```
faculty     title='成绩录入'  科目列=4   输入框=16   拒止=False
backoffice  title='成绩录入'  科目列=14  输入框=56   拒止=False     <- 没有被收窄
student     title='成绩簿'    科目列=0   输入框=0    拒止=False     <- 成绩簿未被波及
parent      title='成绩簿'    科目列=0   输入框=0    拒止=True      <- 未扩大改动面
```

另：教务对 subject 36（**非教师任教**的科目）仍可写入 —— POST m_5_36=62 → saved=1，
result_line 61 -> 62，随后还原回 61。⇒ 收敛只作用于教师，没有误伤教务。
